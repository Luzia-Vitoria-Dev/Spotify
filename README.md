# Spotify Clone 🎵

Este é um projeto que replica a interface e as principais funcionalidades do
Spotify (incluindo uma área de BackOffice), desenvolvido para consolidar
conhecimentos em desenvolvimento web moderno e arquitetura Full-Stack.

## 🛠️ Tecnologias Utilizadas

- **Framework & Core:** Next.js (App Router), React, TypeScript
- **Inteligência Artificial:** IA para suporte na geração e prototipagem do Front-end
- **Estilização & UI:** Tailwind CSS, CSS Global & Local, Sass, Radix UI (Primitives)
- **Arquitetura & Renderização:** Server Components First, Client Components, Suspense, Server Actions
- **Roteamento & Navegação:** Rotas Estáticas, Dinâmicas e de Grupo (`(backoffice)`), Parâmetros via Rota e Query, Navegação Tradicional e Client-Side
- **Banco de Dados & ORM:** PostgreSQL, Prisma ORM, UUIDs
- **Formulários & Validação:** React Hook Form, Zod
- **API & Comunicação:** Route Handlers, SSR, CSR, Request Content-Type
- **Feedback & UX:** React Hot Toast, Tratamento de Erros Customizado (`error.tsx`, `not-found.tsx`)
- **DevOps & Ferramentas:** Docker, Docker Compose, Prettier, ESLint

## ⚙️ Como rodar o projeto localmente

1. Clone o repositório:
   `git clone https://github.com/Luzia-Vitoria-Dev/Spotify.git`

2. Instale as dependências locais (para autocomplete no editor):
   `npm install`

3. Suba o ambiente com Docker:
   `docker compose up`
